# Oracle SQL Practice

This repository contains practical SQL exercises based on Oracle's `hr` schema.

## File structure

| File | Topic |
|---|---|
| `01_basic_select_where.sql` | Basic SELECT, WHERE, LIKE, BETWEEN |
| `02_order_by_aggregate.sql` | ORDER BY, aggregate functions, calculations |
| `03_null_functions.sql` | NULL handling: NVL, NVL2, COALESCE |
| `04_case_decode.sql` | CASE, DECODE, date conditions, nested CASE |
| `05_data_quality_audit.sql` | Data quality audit: LEFT JOIN, FULL OUTER JOIN, and SELF JOIN to find inconsistencies |

## Schema used

All queries are built on the `hr.employees` table, Oracle's standard sample schema.
